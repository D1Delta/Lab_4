## Задание 1

### Класс LineSegment. Пересечение отрезков

#### Текст задачи

Реализовать определение класса `LineSegment` (поля, свойства, конструкторы (не менее трёх), перегрузку оператора вывода для вывода полей, заданный метод согласно варианту). Протестировать все методы, включая конструкторы; все исходные данные вводятся с клавиатуры, данные необходимо проверять на корректность.

**Поля:** `double x`, `double y` (координаты начала и конца отрезка на координатной прямой).

**Метод:** определить пересечение заданных отрезков. Результат должен быть типа `LineSegment` (он равен `null`, если отрезки не пересекаются).

**Средства C++:** класс, конструкторы, геттеры и сеттеры, дружественный `operator<<`, `std::optional`, `std::max`, `std::min`.

**Примеры:**

| № | Входные данные | Результат |
|:-:|---|---|
| 1 | `A: x=1, y=3`<br>`новые значения B: x=2, y=5`<br>`C: x=4, y=6` | `D = [0; 0]`<br>`B (копия A) = [1; 3]`<br>`B после изменения = [2; 5]`<br>`A (не изменился) = [1; 3]`<br>`Пересечение = null (отрезки не пересекаются)` |
| 2 | `A: x=1, y=10`<br>`C: x=3, y=4` | `Пересечение = [3; 4]` |
| 3 | `A: x=1, y=4`<br>`C: x=4, y=6` | `Пересечение = [4; 4]` (отрезки касаются в одной точке) |
| 4 | `x = abc`<br>`A: x=5, y=3` | `Ошибка: нужно ввести число (например, -2.5).`<br>`Ошибка: начало x не должно быть больше конца y. Повторите ввод.` |

#### Алгоритм решения

1. **Поля и свойства.** Координаты хранятся в закрытых полях `x_` и `y_`. Доступ к ним — через геттеры `x()`, `y()` и сеттеры `set_x()`, `set_y()`. Сеттер возвращает `false` и не меняет значение, если передано не конечное число (NaN или бесконечность). Метод `IsValid()` возвращает `true`, если `x <= y` (правильный диапазон).
2. **Конструкторы (три):**
   - по умолчанию — создаёт отрезок `[0; 0]`;
   - с параметрами `LineSegment(double x, double y)`;
   - копирования `LineSegment(const LineSegment&) = default`.
3. **Вывод в поток.** Дружественный `operator<<` выводит поля в формате `[x; y]`.
4. **Метод `Intersect(const LineSegment& other)`:**
   - если хотя бы один из отрезков является неправильным диапазоном (`x > y`), вернуть «null»;
   - вычислить левую границу пересечения `left = std::max(x_, other.x_)` и правую `right = std::min(y_, other.y_)`;
   - если `left > right`, отрезки не пересекаются — вернуть «null»;
   - иначе вернуть `LineSegment(left, right)`. Отрезки считаются замкнутыми, поэтому при `left == right` результатом будет отрезок-точка.
5. **Представление `null`.** В C++ у объекта нет значения `null`, поэтому метод возвращает `std::optional<LineSegment>`: пустое значение (`std::nullopt`) означает «отрезки не пересекаются», иначе внутри лежит объект типа `LineSegment`.
6. **Ввод с проверкой.** Числа читаются строкой и преобразуются функцией `strtod`; ввод повторяется, пока не будет введено число целиком (допускается запятая как десятичный разделитель). Для отрезков в задании 1 дополнительно проверяется условие `x <= y`.
7. **Порядок тестирования в `main`:** конструктор по умолчанию → конструктор с параметрами (ввод отрезка `A`) → конструктор копирования (`B`) → изменение копии через сеттеры (проверка, что `A` не изменился) → ввод отрезка `C` и пересечение `A` и `C`.

## Задание 2

### Класс LineSegment. Перегруженные операции

#### Текст задачи

Добавить к классу `LineSegment` из задания 1 следующие перегруженные операции:

- **Унарная операция** `!` — установить соответствующую координату в 0, чтобы получился правильный диапазон. Ответом должен быть объект `LineSegment`.
- **Операции приведения типа:**
  - `int` (неявная) — результатом является целая часть координаты `y`;
  - `double` (явная) — результатом является координата `x`.
- **Бинарные операции:**
  - `+ целое число` — увеличивается координата `x`, ответом должен быть правильный диапазон;
  - `> LineSegment d` — результат равен `true`, если левый диапазон включает правый, и `false` в противном случае.

В главной функции `main` показать работу всех функций с дружественным интерфейсом.

**Средства C++:** перегрузка `operator!`, `operator+`, `operator>`, неявный `operator int`, явный `explicit operator double`, `static_cast`, `std::trunc`, `std::numeric_limits`.

**Примеры:**

| № | Входные данные | Результат |
|:-:|---|---|
| 1 | `S: x=2, y=8`<br>`d=3`<br>`T: x=3, y=5` | `!S = [2; 8]`<br>`int(S) = 8`<br>`double(S) = 2`<br>`S + d = [5; 8]`<br>`S > T: да`<br>`T > S: нет` |
| 2 | `S: x=5, y=2`<br>`d=1`<br>`T: x=0, y=10` | `S = [5; 2]  (неправильный диапазон: x > y)`<br>`!S = [0; 2]`<br>`int(S) = 2`<br>`double(S) = 5`<br>`S + d = [2; 2]`<br>`S > T: нет`<br>`T > S: нет` |
| 3 | `S: x=3, y=-5`<br>`d=-10`<br>`T: x=1, y=2` | `S = [3; -5]  (неправильный диапазон: x > y)`<br>`!S = [0; 0]`<br>`int(S) = -5`<br>`double(S) = 3`<br>`S + d = [-7; -5]`<br>`S > T: нет`<br>`T > S: нет` |

#### Алгоритм решения

1. **Унарная операция `!`** (метод `operator!() const`, исходный объект не изменяется):
   - если `IsValid()` — вернуть копию отрезка;
   - если `y >= 0`, достаточно обнулить `x` — вернуть `[0; y]`;
   - иначе, если `x <= 0`, достаточно обнулить `y` — вернуть `[x; 0]`;
   - иначе (`x > 0` и `y < 0`) одной координатой не обойтись — вернуть `[0; 0]`.
2. **Неявное приведение к `int`.** Берётся целая часть `std::trunc(y)`. Чтобы избежать неопределённого поведения при слишком больших значениях, результат ограничивается границами `std::numeric_limits<int>`.
3. **Явное приведение к `double`.** `explicit operator double()` возвращает `x`. Вызывается только явно: `static_cast<double>(s)`.
4. **Операция `+ int d`.** Вычисляется `new_x = x + d`, результатом будет `LineSegment(std::min(new_x, y), y)`. Если `x` «перескочила» через `y`, отрезок вырождается в точку `[y; y]`, поэтому результат всегда правильный диапазон.
5. **Операция `>`.** Если хотя бы один из диапазонов неправильный — `false`. Иначе левый отрезок включает правый, когда `x_ <= other.x_ && other.y_ <= y_`.
6. **Демонстрация в `main`.** Отрезок `S` вводится с клавиатуры (здесь разрешён и неправильный диапазон `x > y`), далее по очереди выводятся результаты: `!S`, `int(S)`, `double(S)`, `S + d` (число `d` вводится с проверкой на целое), `S > T` и `T > S` (отрезок `T` вводится с клавиатуры).

#### Принятые допущения

- В условии не уточнено, какую координату обнулять в `!`: обнуляется та, которая делает диапазон правильным (см. шаг 1); если одной координатой не обойтись, обнуляются обе.
- В операции `+` при `x + d > y` отрезок схлопывается в точку `[y; y]`.
- Вложение в операции `>` нестрогое: равные отрезки включают друг друга.
